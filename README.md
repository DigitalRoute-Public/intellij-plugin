# DigitalRoute plugin for IntelliJ IDEA

Update site for the **DigitalRoute** IntelliJ IDEA plugin: the plugin repository index
(`updatePlugins.xml`, served from GitHub Pages) and the signed plugin releases.
The plugin's source is not here, and releases are published only by DigitalRoute's CI.

Plugin repository URL:

https://digitalroute-public.github.io/intellij-plugin/updatePlugins.xml

Add it in IntelliJ IDEA under **Settings > Plugins > ⚙ > Manage Plugin Repositories…**, then
install **DigitalRoute** from the Marketplace tab.

Installation details, requirements and support are in the DigitalRoute product documentation.
